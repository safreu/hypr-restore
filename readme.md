# hypr-restore

Hypr-restore is a tool to track your currently opened application and restore them after booting again.

### Built With
![Rust Edition](https://img.shields.io/badge/rust-2024-orange?logo=rust)

## Installation

Use the package manager [crate](https://crates.io/) to install hypr-restore.

```bash
crate install hypr-restore
```
